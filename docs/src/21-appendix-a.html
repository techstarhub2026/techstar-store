Appendix ACatalogue Taxonomy

The recommended launch taxonomy for a STEM and electronics retailer: 17 categories and 102 subcategories, each with its positional SKU code per §12.1. This is a structural classification of the electronics component trade, not proprietary content — it is the right starting shape, and TechStar should add, rename and reorder freely once real stock is known. Codes are assigned so that a subcategory code always begins with its parent category code. Gaps in the sequence are intentional and reserved.

A.1 Notes on applying this taxonomy

  • Depth is fixed at two levels by the SKU scheme and by the mega-menu design (§9.3.8). Resist a third level; split a subcategory instead.
  • Reserve codes as you go. Leaving gaps — using 00, 10, 20 for the first three subcategories — lets related items be inserted later without renumbering, and SKUs are immutable once assigned.
  • Empty subcategories are hidden from storefront navigation (§6.4.2) but remain fully manageable in the console, so the tree can be built out ahead of stock arriving.
  • Name for the buyer, not the engineer. "Passive devices" is correct and opaque; consider "Resistors, capacitors & inductors" for the STEM half of the audience, with the technical term as a tag.
  • Seed order matters. Categories must be created before subcategories, and both before products, because SKU allocation reads the parent (Appendix F).
