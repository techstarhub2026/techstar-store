7.7 Checkout

Purpose. Convert a cart into a paid order with the fewest possible decisions, without forcing account creation. This is the highest-value screen in the product and the one where the reference platform's design is at its strongest: a single page, no steps, no wizard, everything visible at once.

Two columns at lg and above: the form on the left (8 of 12), the order summary on the right (4 of 12), sticky from the top of the viewport. 7.7.3 Submit sequence

PLACE ORDER pressed
 ├─ client-side validation ─── fail → focus first error, announce, stop
 ├─ button enters loading state, label replaced by spinner, form disabled
 ├─ POST /orders  { customer, items[], shippingMethodId,
 │                  shippingAddress?, paymentMethod, paymentNumber?,
 │                  delegatedPayerEmail?, idempotencyKey }
 ├─ server revalidates EVERY line: product live, variant live,
 │  price unchanged, stock sufficient                      (§12.5.3)
 │    ├─ 409 PRICE_CHANGED  → summary updates in place, amber notice
 │    │                        "Prices have changed. Please review and
 │    │                         place your order again." Button re-enabled.
 │    ├─ 409 OUT_OF_STOCK   → affected lines flagged, quantities clamped,
 │    │                        same re-confirm treatment
 │    └─ 200/201            → continue
 ├─ order created, stock reserved, order number issued  (§12.7)
 ├─ cart cleared client-side and server-side
 └─ navigate to /order/confirmation/:orderNumber
      (if an aggregator returned a hosted checkout URL, redirect there
       instead and return to the confirmation route afterwards — this is
       the `url` field the reference platform's client already honours)
Idempotency The client generates a UUID when the checkout page mounts and sends it as idempotencyKey. The server stores it against the created order and returns the same order for any repeat of the same key within 24 hours. A double-click, a flaky mobile connection or an impatient refresh must never create two orders — on a payment screen this is not a nicety.
